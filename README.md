## 💻 Local Development

1. **Clone or Open the Repository**:
   ```bash
   cd a010
   ```

2. **Install Dependencies**:
   ```bash
   npm install
   ```

3. **Start Development Server**:
   ```bash
   npm run dev
   ```
   Open [http://localhost:5173/](http://localhost:5173/) in your browser.

4. **Build Production Bundle**:
   ```bash
   npm run build
   ```
   The production-ready assets are compiled into the `dist/` directory.

## 🌐 Deployment to GitHub Pages

Since your portfolio repository is at `https://github.com/aniljogi123/portfolio/`:

1. In `package.json`, ensure the base path is set to `./` (already configured in `vite.config.ts`).
2. Run the build command:
   ```bash
   npm run build
   ```
3. Deploy the `dist` folder to your `gh-pages` branch or configure GitHub Pages in your repository settings:
   - Go to **Repository Settings** > **Pages**.
   - Under **Build and deployment** > **Source**, choose **GitHub Actions** (using the standard Vite/Static HTML workflow) or select the `gh-pages` branch.

Alternatively, you can install `gh-pages`:
```bash
npm install -D gh-pages
```
Add to `package.json` scripts:
```json
"deploy": "gh-pages -d dist"
```
And run:
```bash
npm run deploy
```
